## Reflection

The most challenging part of this assignment was figuring out how to turn each problem into clear steps the program could follow. Some scenarios required loops for repeated input, conditions for different situations, and checks to prevent invalid values from causing incorrect results.

I worked through these challenges by breaking each problem into smaller parts, choosing suitable variables, and using conditional statements and loops where needed. Testing the programs with different inputs helped me find mistakes and check that the results made sense. Overall, this assignment gave me more practice with Python and helped me understand how programming can be used to solve everyday problems.
